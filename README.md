## 📌 项目简介

**《我的奇妙旅行 (My Wonderful Journey)》** 是一款基于 **Python (Pygame)** 开发的 2D 交互式英语拼写游戏。

- **目标受众**：6–12 岁儿童，尤其是患有 **ADHD（注意力缺陷多动障碍）** 和**色弱**的儿童
- **核心理念**：用情境化游戏代替枯燥的单词表，让学习自然发生
- **AI 辅助开发**：核心代码由 [CodeBuddy.ai](https://codebuddy.ai) 生成，总成本 **不到 ¥40**

---

## 🧠 HCI 设计原则

游戏将**人机交互（HCI）原则**刻入设计核心：

### 🎨 情境化学习（Contextualization）
让单词与真实场景绑定（超市购物、森林探险），例如去野餐时才会拼写 "Apple" 和 "Backpack"。

### 🔊 多模态展示（Multimodal）
照顾色弱和阅读障碍儿童，**绝不单纯依赖颜色区分对错**，融合：
- 文字 + 图片 + 音标 + TTS 语音引导 + 动物音效
- 听觉、视觉、交互三管齐下

### ❤️ 极致的宽容度（Forgiveness）
- 拼错字母：**轻轻晃动消失**，伴随温柔语音鼓励「再试一次」
- 提供【家长求助】按钮：自动填入一个正确字母
- 核心原则：**绝不让孩子产生挫败感**

## 🏆 游戏场景

| 场景 | 内容 |
|------|------|
| 🏠 **客厅起步** | 引入背景故事，用可爱「小手套」游标选择目的地 |
| 🛒 **超市采购** | 点击目标物品进入拼写，完成采购清单 |
| 🌲 **森林探险** | 翻动物手册、听配音、进入剧情对话、解锁动物拼写 |
| ⏳ **挑战模式** | 初/中/高三级倒计时挑战，冲击三星评分 |

## 🎨 UI 制作方法

**「PPT 编辑 + AI 美化」的缝合魔法：**

1. 从 [Kenney.nl](https://kenney.nl) 获取免费可商用像素图块
2. 用 **PowerPoint** 拼接图块、抠图、组合元素
3. 将初稿喂给 **AI（GPT/Gemini）** 进行 16:9 外扩图和清晰化处理

> 效果：风格极度统一，省下大笔外包美术费用

## 💻 AI 辅助开发实录

### 🤖 AI 负责建构「骨架」
- 将详尽策划案输入 **CodeBuddy.ai**
- 迅速生成包含 **13 个 Python 文件**的**状态机架构（State Machine）**
- 主循环、场景切换、淡入淡出框架瞬间成型

### 🧑‍💻 人类负责「坐标地狱」与手感微调
- 原画分辨率：**2560×1440** → 游戏运行窗口：**1280×720**
- 精准计算 26 键字母键盘每个按键的点击区域（格子大小 66×66）
- 场景切换淡入淡出从 1 秒优化至 **0.5 秒**（60FPS）

## 🚀 快速开始

### 环境要求

```
Python 3.8+
pygame
```

### 安装依赖

```bash
pip install pygame
```

### 运行游戏

```bash
cd game
python main.py
```

> ⚠️ 请确保 `game/`、`场景图/`、`音频/` 三个文件夹位于同一目录下。
